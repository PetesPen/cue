# Sprint 0 spike code (archived)

Throwaway experiments from sprint 0, kept so the findings in `docs/spikes/` can be reproduced. Not part of the app: excluded from the build, the type check and the linter. Do not build on it; the real code lives in `src/`.

Run one with `SPIKE=sp-N npx playwright test -c spikes/playwright.config.ts --project=chrome` or serve it by hand with `npm run spike:sp-N`. See `docs/spikes/README.md`.
