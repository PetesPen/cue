# Brand

`working-logo.png` is the working logo Peter gave on 2026-10-18: three stacked layers in orange, on a transparent background (about 1250 × 1120 px, soft edges). It is the source of the app icons in `public/` (`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon-48.png`). Make them again with `npm run icons`.

It is a working logo: the final art, ideally as a vector (SVG), replaces the file and the icons are made again. The wordmark and the mark in the app's top bar are the design's (`design/`) and are not changed by this.
